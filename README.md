# Database - GoMyCode

Exercices et projets réalisés dans le cadre de la formation GoMyCode, couvrant les bases de données et les structures de données.

## Contenu

### Data Structures

Implémentations de structures de données en JavaScript et Python :

- **Basic** — Système de gestion de contacts utilisant une liste doublement chaînée, une table de hachage et la recherche de sous-chaînes (`contacts.js`, `contacts.py`)
- **Advanced** — Implémentation d'un tas (heap) et d'une file de priorité (`heap.js`)

### Relational Databases

- **Data Definition Language** — Commandes DDL (CREATE, ALTER) pour créer et modifier des tables CUSTOMER, PRODUCT et ORDERS (`DDL_commands.sql`)
- **Entity–Relationship Model** — Modélisation entité-association
- **Relational Model** — Modèle relationnel

### NoSQL Cloud Datastores

- **Introduction to Databases: SQL vs NoSQL** — Présentation comparative MongoDB vs SQL (`MongoDB_vs_SQL.pptx`)

## Technologies

- SQL (Oracle)
- JavaScript
- Python
- MongoDB
